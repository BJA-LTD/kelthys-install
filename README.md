# Kelthys apps: install page

The web page that installs our desktop apps on a Windows PC or a Mac, or adds the phone companion:

- **Kelthys - Protect & Optimisation**: https://bja-ltd.github.io/kelthys-install/guard/
- **Kelthys PDF**: https://bja-ltd.github.io/kelthys-install/pdf-desk/

The install files are on the [Releases](https://github.com/BJA-LTD/kelthys-install/releases/latest) page. Each one carries
the official Node.js from nodejs.org; nothing else is downloaded. The installers are not signed with a paid certificate,
so Windows SmartScreen and macOS Gatekeeper warn on first run: the page says what to click.
